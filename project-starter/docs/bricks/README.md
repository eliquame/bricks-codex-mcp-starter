# Bricks Project Knowledge Base

This directory is initialized automatically by the one-prompt `START-HERE.md` workflow.

Before the full site audit, it may contain only:

- this README;
- `00-bootstrap-status.md`, which stores setup/restart/resume state.

The full bootstrap audit then populates verified, site-specific documentation such as:

- audit progress and site state;
- site inventory and settings;
- design system and ownership;
- Theme Styles, classes, variables/tokens, colors, typography, and breakpoints;
- page and template architecture;
- components;
- plugin/data architecture where relevant;
- dynamic data and queries;
- WooCommerce when active;
- frontend visual references and responsive patterns;
- site rules, known patterns, and audit findings;
- machine-readable snapshots where useful.

The exact set of files is conditional on the site. Do not create empty documentation merely to satisfy a template.

Local documentation is a durable cached reference, not a substitute for current live MCP/browser verification before writes.

Never copy site-specific knowledge from another project into this directory.
